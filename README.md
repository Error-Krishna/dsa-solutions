## 📂 Repository Structure

Every successfully solved LeetCode problem is automatically synchronized to this repository using LeetSync.

Each problem has its own dedicated folder directly inside the repository root, containing:

- `README.md` — Problem statement, difficulty, examples, and constraints.
- `.java` file — Java implementation of the solution.


## ⚙️ Automated LeetCode Synchronization

This repository is configured with **LeetSync** to automate the synchronization of accepted LeetCode submissions with GitHub.

Whenever a problem is successfully solved and accepted:

1. LeetSync detects the accepted submission.
2. A dedicated folder is created for the problem.
3. The problem statement and relevant details are added to `README.md`.
4. The submitted solution is added as a `.java` file.
5. Changes are automatically committed and pushed to GitHub.

This keeps the repository updated automatically without requiring manual uploads after every successful submission.

## 💡 Problem-Solving Approach

For every problem, the focus is on:

1. Understanding the problem statement and constraints.
2. Identifying a brute-force approach.
3. Analyzing time and space complexity.
4. Finding an optimized solution.
5. Implementing the solution in Java.
6. Testing edge cases.
7. Understanding the underlying DSA pattern.

The objective is to understand the reasoning behind every solution rather than simply obtaining an accepted submission.
